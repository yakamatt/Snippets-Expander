Snippet Expander

Bienvenue 👋

Rédigez vos rapports AVISO beaucoup plus vite

Snippet Expander remplace un raccourci court par un texte complet, et ajoute à Aviso des icônes qui insèrent les dispositions types en un clic.

Une minute pour faire le tour : suivez les flèches.

Étape 1 · Au clavier

Tapez un déclencheur, il devient un texte

Un déclencheur commence par /. Après une courte pause, il se remplace tout seul par son contenu.

  • ✅ Dans tous les champs de texte : Aviso, Gmail, formulaires…
  • ✅ Y compris le champ Remarque d'Aviso
  • ✅ {date} et {time} deviennent la date et l'heure du jour
Dispositions réalisées
⏱️ Remplacé après 0,5 s de pause (réglable dans les Paramètres)

Étape 2 · D'où viennent les textes

Deux clausiers, le vôtre passe en premier

Si les deux ont le même déclencheur, c'est votre snippet personnel qui s'insère.

🛟 Sauvegarde anonyme

Une copie anonyme de votre Clausier Personnel est envoyée au tableau du Clausier Commun, pour l'enrichir des formulations utiles à tous. Elle ne permet pas de restaurer vos snippets : exportez-les régulièrement (Paramètres › Clausier Personnel). Désactivable dans Paramètres avancés.

Clausier Commun

Partagé par toute l'équipe, dans un Google Sheets.

🔄 Mis à jour automatiquement toutes les heures

Clausier Personnel

Vos propres textes, créés sur Aviso ou dans les Paramètres.

Étape 3 · Sur Aviso

Un clic pour remplir « Dispositions réalisées »

Sur chaque ligne dont le Référentiel porte un code (GN 4, CO 24…), des icônes apparaissent au-dessus du champ.

Un clic ajoute le texte à la suite de ce qui est déjà écrit : rien n'est remplacé. Survolez une icône pour relire le texte avant de l'insérer.

RéférentielDispositions réalisées
GN 4 - Procédure d'adaptation
Les dispositions prévues ont été vérifiées…

Insérer un texte

  • Votre snippet celui de votre Clausier Personnel pour ce code
  • Clausier Commun le texte partagé par l'équipe
  • DatAviso AI les données du dossier que vous avez importées

Gérer vos snippets

  • Modifier votre snippet, sans quitter Aviso
  • Créer un snippet à partir du texte de la cellule. Il remplace l'icône jaune tant que vous n'avez pas de snippet pour ce code

Et aussi

  • Réglementation l'article sur sitesecurite.com
  • Effacer le champ. Un second clic annule

Étape 5 · Retrouver l'affaire

SGO, SharePoint et dossiers en un clic

À partir du numéro d'affaire, trois liens ouvrent :

  • SGO la fiche de l'affaire dans SGO
  • ShP la recherche du numéro dans SharePoint
  • C:\ la recherche dans l'Explorateur Windows

Chacun se désactive dans Paramètres avancés.
