Partage & synchro via Google Sheets (gratuit)

1. Créez un Google Sheet avec un onglet "Snippets" (colonnes trigger / content / description / folder).
2. Déployez le script fourni (voir README) comme "Web App".
3. Collez l'URL ci-dessous. La récupération fusionne avec vos snippets locaux — rien n'est perdu.
