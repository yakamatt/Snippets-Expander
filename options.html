Mise à jour de l'extension

Cette extension a été installée depuis le Chrome Web Store : les mises à jour se font automatiquement en arrière-plan, gérées par Chrome. Aucune action de votre part n'est nécessaire.

Mise à jour de l'extension (mode développeur)

Aucune donnée locale n'est perdue lors d'une mise à jour tant que vous remplacez les fichiers dans le même dossier.

  1. ⬇️ Télécharger le zip de la nouvelle version
  2. Décompressez le fichier téléchargé
  3. Remplacez les fichiers dans le même dossier que celui actuellement chargé dans Chrome (ne créez pas un nouveau dossier)
  4. Ouvrez chrome://extensions
  5. Cliquez sur l'icône Actualiser ⟳ de la carte "Snippet Expander"
